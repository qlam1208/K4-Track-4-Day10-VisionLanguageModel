# Bằng chứng GPU

Các file `e0.json`–`e3.json`, `e4_rank_4.json`, `e4_rank_64.json` ở đây phải được
`scripts/score.py` gốc tạo từ raw suy luận thật. Thiếu những file này nghĩa là chưa
hoàn thành các thí nghiệm bắt buộc. `../diagnostics/` chứa kiểm tra dữ liệu/cấu trúc,
không được sao chép hoặc đổi tên thành bằng chứng model. Xem RUNNING.md và notebook Colab.
